## About

I'm a Computer Engineering student at **Istanbul Technical University** working on autonomous systems, robotics, database systems, estimation, and real-time software.

My interests are in working on complicated things: the kind of problems where perception, planning, data, and software architecture all have to work together, and where a system has to stay fast and reliable under real-world constraints. I enjoy breaking hard problems into clean, well-structured components and building them until they run on real hardware.

```text
Autonomy     Path Planning · Motion Planning · Autonomous Vehicles
Perception   LiDAR Processing · Point Clouds · Ground Detection · Filtering
Estimation   State Estimation · Sensor Fusion · Kalman Filtering
Data         Database Systems · Data Modelling · Query Design
Software     C++ · C · SQL · Verilog · OOP · Real-Time Systems
```
